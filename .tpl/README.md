# 模板使用说明

先读 template.json 与 project.json。应用能力、命令与端口见根 README.md。默认中文，英文在 /en；语言切换保持页面、查询和锚点。

修改入口见 customization.json。品牌、双语内容、主题令牌、公共组件、页面组合、路由分别维护。公开页面结构依据参考预览实现，不包含受限源码。

运行检查会生成编译缓存；安装需要网络，无业务持久化。表单、图表和价格均为演示，不发送请求或执行交易。

完整验收事实见 docs/VERIFICATION.md；未验证项不能视为通过。素材权利见 docs/LICENSE.md、docs/ASSETS.json。
