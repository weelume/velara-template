# Velara AI

双语智能财务官网，包含首页、功能、价格、关于、手记与三篇文章、联系、隐私及条款。

先读 [.tpl/README.md](.tpl/README.md)。Node 24.16.0，pnpm 9.15.4。`pnpm install --frozen-lockfile` 安装；`pnpm dev` 启动，默认 http://127.0.0.1:43620，Ctrl+C 停止。`pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 验证；`pnpm start` 预览生产服务。

账户、图表、价格与评价均为演示。表单仅本地校验，不发送、不保存。不提供真实金融服务。第三方视频与参考设计的再分发权利待核实，未上架。
